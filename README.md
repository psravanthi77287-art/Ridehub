# RideHub 🚴

A bike rental web application where users can browse bikes, register, log in, and book rides.

## Features
- Browse available bikes
- User registration and login
- Bike booking page
- Contact page
- Responsive design

## Tech Stack
- HTML
- CSS
- JavaScript

## Project Structure
- `frontend/` - web pages and styles

## How to Run
1. Clone this repository
2. Open the `frontend` folder
3. Open `index.html` in your browser
